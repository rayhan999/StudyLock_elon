# StudyLock

**Study first, scroll later.** StudyLock locks your distracting apps every day until you've spent your daily goal (default 30 min) in your study apps — like an online course such as [elon.io](https://elon.io). Hit the goal and everything unlocks until midnight.

Built with Expo / React Native, with native code for Android and iOS.

## How it works

| | Android | iOS |
|---|---|---|
| Counts study time | `UsageStatsManager` — foreground time in your study apps since midnight | Screen Time `DeviceActivity` threshold events (every 5 min) |
| Blocks apps | Accessibility service bounces you back to StudyLock | Screen Time shields (`ManagedSettings`) |
| Daily reset | Automatic — time is always counted from midnight | Monitor extension re-locks at 00:00 |
| Status | ✅ Working build (APK) | ⏳ Waiting for Apple's Family Controls approval |

Rules that keep it honest:

- **Never blocked:** StudyLock, your study apps, the apps you mark "always allowed" (Phone, Messages, Maps…), plus the launcher, keyboard and system Settings.
- **Settings are locked too** — goal and app lists can only be changed after today's goal is met.
- Studying a website? On Android, open it in Chrome → ⋮ → **Add to Home screen**; it becomes its own app you can pick. On iOS, pick the website itself in the Screen Time picker.

> StudyLock is a self-control tool, not a prison: you can always switch it off in system settings. For a strict lock, let someone else set your Screen Time / Digital Wellbeing passcode.

## Install on Android

1. Build an APK in the cloud (no Android Studio needed):
   ```bash
   npx eas-cli@latest build -p android --profile preview
   ```
2. Open the build link on your phone and install the APK.
3. In StudyLock, grant **Usage access** and enable the **Accessibility** service.
   On Android 13+, if the toggle is greyed out ("Restricted setting"): App info → ⋮ → **Allow restricted settings**.
4. Pick study apps + always-allowed apps, set a goal, tap **Start**.

## iOS (pending)

Screen Time APIs need Apple's **Family Controls (Distribution)** entitlement before anything can be installed. Request it for all four bundle IDs at <https://developer.apple.com/contact/request/family-controls-distribution>:

- `studylock.com.app`
- `studylock.com.app.ActivityMonitorExtension`
- `studylock.com.app.ShieldAction`
- `studylock.com.app.ShieldConfiguration`

Once approved:

```bash
npx eas-cli@latest build -p ios --profile production --auto-submit
```

…then install via TestFlight.

## Project structure

```
App.tsx                        iOS UI (onboarding, progress, settings)
App.android.tsx                Android UI (permissions, app pickers, progress)
src/lock.ts                    iOS lock logic on top of react-native-device-activity
modules/studylock-android/     Local Expo module (Kotlin)
  ├─ Lock.kt                   study-time counting + "is this app blockable?"
  ├─ BlockService.kt           accessibility service that enforces the lock
  └─ StudyLockAndroidModule.kt JS bridge (app list, config, permissions)
targets/                       iOS extensions (generated by the device-activity config plugin)
STUDYLOCK_IMPLEMENTATION_PLAN.md  design notes and decisions
```

`ios/` and `android/` are generated by `expo prebuild` — don't edit them by hand.

## Development

```bash
npm install
npx tsc --noEmit          # typecheck
```

Expo Go can't run this app (it uses custom native code). Use EAS builds as above.

## Known limitations

- Android counts foreground time, iOS counts screen time in 5-minute steps — neither can tell if you're actually paying attention.
- Android can't see which website is open in Chrome — install the site as a home-screen app instead.
- Not on the App Store / Google Play yet. Publishing needs Apple's entitlement approval and a Google Play Accessibility API declaration.
