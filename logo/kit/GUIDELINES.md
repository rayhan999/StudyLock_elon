# Sanalukko logo guide

**Idea:** the umlaut dots join into a shackle, so the ä becomes a lock. *Sana* (word) + *lukko* (lock) in one shape.
The coral shackle is the part that "opens" when today's goal is met. Use it for motion and reward moments.

## Colour

| | HEX | RGB | CMYK (approx.) | Role |
|---|---|---|---|---|
| **Navy** | `#1A3F8F` | 26 63 143 | 100 80 5 5 | The a, text, buttons |
| **Coral** | `#FF6B5B` | 255 107 91 | 0 70 60 0 | Shackle, progress, accents only |
| **Cream** | `#FFF4E6` | 255 244 230 | 0 4 10 0 | Background |
| Muted (UI) | `#5A6480` | 90 100 128 | — | Secondary text |

Contrast: navy on cream 9.0:1 ✅. Coral on cream is only 2.6:1, so **never set text in coral**; use it only for the
shackle and decorative fills. For print, match Pantone values with a swatch book; the CMYK values above are starting
points.

## Clear space and minimum size

- **Clear space:** keep a margin equal to the shackle's height around the mark or lockup on all sides.
- **Symbol:** minimum 16 px. Switch to `symbol-small.svg` at 32 px and below.
- **Horizontal lockup:** minimum 96 px wide. Below that, use the symbol alone.

## Approved backgrounds

Cream (preferred), white, navy (reversed version). On photos, use the one-colour white or navy version on a calm area.

## Don't

- Recolour the shackle navy while the a stays navy. In full colour the shackle is always coral; in one colour, everything is one colour.
- Close the gap between the shackle and the a, or attach the shackle to the a.
- Swap in a double-storey "a" or a font's own a; the custom single-storey a is part of the mark.
- Stretch, rotate, outline, add shadows or gradients.
- Use coral for text or as a full background behind the navy mark.

## Typography

Wordmark: Avenir Next Bold (outlined) with the custom single-storey a. **Licence note:** Avenir Next ships with macOS
but is a Monotype font. Buy a desktop licence before commercial use of the wordmark artwork, or redraw it in an open
font (e.g. Nunito Sans / Figtree, OFL). In the app UI, use the system font.
